# Portfolio

70s-retro single-page portfolio built with Vite, React, TypeScript and Framer Motion.

- **Full Stack** — an FM radio tuner: drag the dial or pick a preset to switch stations.
- **Ad Tech** — a header-bidding auction simulator: consent → traffic check → Prebid → GAM → render.

Content (skills, stations, projects, links) lives in `src/data.ts`.

```sh
npm install
npm run dev       # http://localhost:5173/portfolio/
npm run build     # typecheck + production build to dist/
npm run deploy    # publish dist/ to the gh-pages branch
```
